## Independent industrial restructuring assessment

I can answer the verification question directly.

### What is needed to determine whether a non-closure package closes the gap
At minimum, I would need:

1. **Plant-by-plant capacity and utilization**
   - rated capacity
   - current output
   - planned output by model and year

2. **Workforce by site and function**
   - direct labor
   - indirect labor
   - salaried overhead
   - temporary labor

3. **Full cost stack by plant**
   - direct labor cost
   - indirect labor
   - maintenance
   - utilities/energy
   - logistics
   - plant overhead
   - depreciation/capital charge
   - central allocation

4. **Baseline financial target**
   - current ROS / EBIT
   - target ROS / EBIT
   - annual recurring savings needed
   - one-time restructuring budget available

5. **Measure-by-measure savings assumptions**
   - working-time changes
   - wage/bonus moderation
   - productivity gains
   - voluntary exits/retirements
   - redeployment
   - qualification/retraining costs
   - purchasing/sourcing savings
   - management overhead reductions

6. **Implementation timeline**
   - when each saving begins
   - ramp-up curve
   - risk of slippage

7. **Restructuring friction costs**
   - severance
   - transfer costs
   - retraining
   - legal/consulting/IT/process costs
   - production disruption risk

### Minimum document set I would request
- plant P&Ls or comparable site-cost statements
- capacity and utilization report by line/site
- headcount by function and site
- wage and labor-cost detail
- planned model allocation / platform map
- investment and depreciation plan
- restructuring measure impact model
- scenario model showing:
  1. non-closure package
  2. mixed package
  3. closure-based package

### How quickly this can be verified
If the company provides clean management accounts and site data, a **first-pass verification** can usually be done in **2–4 weeks**.  
A more defensible, audit-grade review typically takes **4–8 weeks**, depending on data quality and the number of sites.

### Technical view on plausibility
On the facts given, a **non-closure package is technically plausible**, but I cannot say it is sufficient without the numbers. The key determinant is whether the gap is mostly:
- **labor and overhead inefficiency**, which non-closure measures can partially fix, or
- **excess fixed footprint / underutilized plants**, which is harder to solve without site changes.

### Practical conclusion
- If the required savings are **moderate** and utilization is recoverable, a non-closure package may be enough.
- If the required savings are **large** and the German footprint is structurally underutilized, non-closure measures may close only part of the gap.

So the correct next step is a **plant-by-plant savings bridge** and a **common scenario model**. Without that, no one can honestly claim that closures are either unavoidable or unnecessary.
