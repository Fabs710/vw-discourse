## Short answer
A **strong no-closure package can plausibly generate several hundred million euros of recurring annual savings**, but it is **not automatically sufficient** to eliminate the need for deeper structural action.

## Practical estimate
For a large German automotive group/brand footprint, a serious negotiated package built around:
- attrition / non-replacement
- voluntary exits
- redeployment and qualification
- working-time and shift changes
- productivity measures
- a limited employee contribution

will often land in the range of:

- **€200m–€300m p.a.** for a solid package
- **€300m–€500m p.a.** for a strong, well-executed package
- **€500m–€800m+ p.a.** only if concessions are unusually deep and headcount reduction is substantial

## What that means for the closure debate
- If the company’s **remaining gap** after that package is **small**, then a no-closure restructuring is economically credible.
- If the remaining gap is still **material**—for example **€100m–€400m+ p.a.**—then management and capital will keep closures or other footprint changes in play.
- Non-closure tools can soften overcapacity, but they usually **cannot fully solve hard physical overcapacity** if the plant network is structurally too large.
