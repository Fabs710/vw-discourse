## Expert assessment: what is the minimum credible restructuring package?

Within the information given, a **credible 2030 turnaround** for a large German carmaker with structurally high factory costs likely needs **about €1bn per year of recurring structural savings at minimum**, and plausibly **€1.2bn–€1.8bn** if the cost gap is as severe as management implies.

### Why that range is credible
This is not a precise model output — it is an industrial benchmark range based on:
- a large domestic passenger-car footprint,
- multiple plants and meaningful fixed-cost overhead,
- a weak margin position,
- and the need to improve profitability by several percentage points by 2030.

If the required improvement is materially less than that, a no-closure package has a better chance. If the true gap is much larger, a no-closure package is unlikely to be sufficient.

---

## Can a no-closure package work?

### Short answer
**Only if it still removes real capacity and fixed cost.**  
A “no closure” package is not the same as “no footprint reduction.” If all German plants remain fully in place and fully protected, the package is usually **too weak** unless labor concessions are unusually deep.

### What would have to be true
A no-closure package can be credible only if several conditions hold:
1. The current savings gap is **moderate**, not extreme.
2. Capacity can be reduced by **volume transfer, shift elimination, line consolidation, or repurposing**, even without formal plant closure.
3. Employee-side contributions are **large and durable**.
4. Management and owners contribute visibly.
5. There is a **hard enforcement mechanism** if savings are missed.

If any of those is missing, the package likely delays the problem rather than solves it.

---

## What savings mix would be needed?

For a package to be economically credible, I would expect something like:

### 1) Labor-cost and workforce measures
**€300m–€500m per year**  
Possible instruments:
- wage/bonus restraint,
- working-time flexibility,
- longer average working time,
- reduced guarantees,
- redeployment,
- qualification,
- voluntary exits.

### 2) Productivity and overhead simplification
**€200m–€400m per year**  
Possible instruments:
- logistics simplification,
- procurement efficiency,
- engineering complexity reduction,
- fewer variants,
- indirect-function cuts,
- process simplification.

### 3) Capacity reduction / footprint adjustment
**€200m–€500m per year**  
This is the difficult part. It can come from:
- removing underloaded shifts,
- consolidating volumes,
- converting a site,
- downsizing weaker plants,
- reducing fixed plant overhead.

### Combined minimum
That gets you to roughly **€700m–€1.0bn** recurring annual savings, which I would regard as the **minimum credible order of magnitude** for a no-closure compromise.

## What does that mean for the current options?

### Option A: Blanket no-closure, no-forced-redundancy settlement
**Probably not credible** unless:
- the labor contribution is exceptionally deep,
- and there is substantial hidden capacity flexibility.

If “no closure” also means “no real capacity removal,” then the economics are usually insufficient.

### Option B: Differentiated site strategy
**More credible** than a blanket freeze.

This can work if it includes:
- protected core sites,
- conversion of weaker sites,
- real volume reduction,
- lower fixed cost,
- voluntary and redeployment-based workforce reduction.

This is the most realistic way to achieve savings **without formal closures**, but it still requires real footprint adjustment.

### Option C: Closure-first restructuring
Economically this is often the **cleanest** route to savings, but your scenario shows it may be governance-blocked. So the question is not whether it is neat in theory, but whether it is enforceable in practice. On the facts given, it may not be.

---

## My judgment on feasibility

### A pure no-closure / no-redundancy package:
**Economically weak unless the savings gap is small or the labor contribution is very large.**

### A differentiated no-closure package with real site conversion and capacity shedding:
**Potentially credible**, if it achieves around **€1bn recurring savings** and is backed by binding milestones.

### A package built mainly on promises, working-time tweaks, and voluntary measures:
**Not enough** for a structural 2030 reset.
