### Core impasse
The central impasse is this:

- **Management / owners / investors** want **structural cost and capacity reduction**, with closures still available if needed.
- **Works council / union / state** want **no German plant closures and no compulsory redundancies**, with meaningful co-determination preserved.
- Both sides agree the current structure is unsustainable, but they disagree on **whether closure is a necessary instrument or a last resort not yet justified**.

So the unresolved point is not the diagnosis; it is the **acceptable instrument mix** and the **burden of proof** for proving equivalence between closure and non-closure options.

---

### Facilitator compromise proposals

#### 1) Sequenced restructuring with a hard review gate
A compromise could be a **phased package** in which:
- immediate internal measures start first: wage moderation, bonus restraint, voluntary exits, redeployment, working-time flexibility, management overhead cuts, and owner-side support;
- plant-level data is reviewed by an independent expert;
- closures are **not implemented immediately**, but remain a **conditional backstop** only if quantified targets are missed after a defined period.

This would try to bridge:
- labour’s demand for no premature closures,
- and management’s demand for enforceable fallback options.

#### 2) Hybrid package with site protection for strategic plants
A second compromise could be a **hybrid footprint plan**:
- preserve strategically important German plants under binding site-security commitments;
- concentrate capacity reductions at the weakest sites or through line/product shifts;
- pair this with stronger employee concessions and management/owner contributions.

This would try to bridge:
- the state and labour’s desire to preserve the industrial base,
- and capital’s need for real structural savings.

#### 3) Binding no-closure commitment tied to quantified equivalence
A third option is a **binding no-closure agreement** for a fixed period, but only if:
- an independent valuation shows the no-closure package reaches a defined threshold of closure-equivalent savings;
- there is enforceable implementation governance;
- and the package includes automatic escalation measures if targets are missed.

This would try to bridge:
- labour’s red lines,
- while giving management and investors measurable performance protection.

### Pointed question to each stakeholder

#### Works Council
If a no-closure package can be shown plant by plant to deliver near-equivalent present-value savings, with binding capacity reduction and enforceable implementation, would you accept a time-limited review mechanism that allows only limited, targeted fallback measures if targets are missed?

#### Industrial Union
What specific concessions are you prepared to quantify up front so the no-closure package is not only politically firm, but financially credible on a present-value basis?

#### Group & Brand Management
Will you commit to a fully transparent plant-by-plant comparison, using the same assumptions for closure and non-closure scenarios, and refrain from announcing closures before that comparison is independently validated?

#### Regional State Government
If the independent analysis shows that only a hybrid package can preserve both competitiveness and the regional industrial base, are you prepared to support a targeted footprint adjustment rather than insist on a blanket no-closure line?

#### Controlling Family Holding
What concrete owner-side contributions are you prepared to place on the table now, so that burden-sharing is visibly not being pushed downward onto labor alone?

#### Institutional Investors
What minimum risk-adjusted return and savings durability threshold would you require for a no-closure package to be acceptable in place of closures?

#### Independent Expert
What minimum evidence would you need to conclude that a no-closure package is genuinely equivalent, rather than merely a delayed version of the same restructuring problem?
