### Core impasse

The dispute has narrowed to one central conflict:

**How much present value can be allocated to the retiree trust, while still keeping bondholder recoveries comparable and leaving enough value for a smaller, financeable company?**

Everything else is downstream of that:
- the trust wants a **meaningful, durable floor**;
- bondholders want **no superior unsecured treatment** for the trust;
- management says the package must not **reintroduce insolvency**;
- neighbouring governments want **protected domestic capacity and equity**;
- the task force will fund only if the result is **viable and not subsidy-dependent**.

So the impasse is not “whether to restructure,” but **where the value floor sits, and what footprint is still supportable once that floor and the regional protections are included**.

---

### Facilitator compromise options

#### 1) Tiered trust floor with contingent step-up
A possible bridge is a **three-tier trust instrument**:
- a **small guaranteed floor** payable after a delay,
- a **second contingent tranche** that activates only if post-restructuring performance targets are met,
- and a **capped upside participation** so the trust retains meaningful future value.

This may allow the union/trust to claim durability while giving bondholders and the task force a clearer ceiling on economic burden.

#### 2) Parity-based unsecured value test
Another possible compromise is to require that:
- the **trust and bondholders receive different instruments if needed**,
- but their **present-value recoveries must fall within a defined band** unless one class receives an explicit offset.

That would preserve the trust’s distinct treatment without allowing it to become economically senior in substance.

#### 3) Protected domestic core in exchange for deeper rationalization elsewhere
A third compromise is to define a **hard protected domestic core** for the neighbouring governments, but only in exchange for:
- more aggressive closure of non-core plants,
- clearer workforce reductions,
- and stronger creditor haircuts.

This could make regional commitments more compatible with the task force’s viability test, provided the protected footprint is tightly limited.
